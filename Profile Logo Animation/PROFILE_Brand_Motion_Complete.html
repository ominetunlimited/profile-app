React Component Usage

// Import the component
import ProfileLogo from '@profile/logo';

// Basic usage
<ProfileLogo
  state="loading"    // loading | connecting | syncing
  size={120}         // sm | md | lg | xl | number
  color="primary"   // primary | white | dark | auto
  speed={1}          // 0.5 – 2.0
  loop={true}
  showLabel={true}  // optional label under logo
  className=""
/>

All State Values

// state prop — one of:
"loading"      // 01 App launch / page load
"connecting"   // 02 Server connection
"syncing"      // 03 Data sync / updating
"success"      // 04 Completed action
"offline"      // 05 No internet
"error"        // 06 Unexpected error
"retry"        // 07 Retry / attempting
"searching"    // 08 Search / discover
"processing"   // 09 Processing / verify
"idle"         // 10 Idle / standby

// Animation guidelines
easing: easeInOutCubic
duration: 1.2s – 2.5s
performance: 60fps, GPU-accelerated
accessibility: prefers-reduced-motion

Animation Guidelines

// Design Principles
Style:     Smooth · Premium · Subtle
Duration: 1.2s – 2.5s (loop seamlessly)
Easing:   easeInOutCubic
Colors:   Brand Blue + Accent Cyan
           + Semantic Red / Green
Loop:     Infinite (where needed)
FPS:      60fps, GPU-accelerated
Format:   SVG + CSS Animations
           Lottie JSON compatible
Sizes:   16px – 512px adaptive

Usage Notes

// Rules for implementation

✓ Never block the user with animations
✓ Always communicate system state
✓ Use consistent timing across app
✓ Ensure accessibility at all times
✓ Build trust through motion clarity

✗ Never spin or bounce the logo
✗ Never use aggressive flashing
✗ Never override user's motion prefs
✗ Never animate without purpose
✗ Never redesign the official logo
