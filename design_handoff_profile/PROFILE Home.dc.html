Ordering logic
Mobile leads with the two numbers a professional checks on their phone, then actions, then activity. The right-hand sidebar cards do not stack in the same order they appear on desktop — matched opportunities and verification progress move below activity, since neither is a phone-sized decision.
Every action has a destination
Record work → /activity/new · How this is calculated → /trust/score · See the gap → /career/readiness · Open record → /records/:id · Trust Center → /trust · All opportunities → /opportunities · Later → dismisses for 7 days, re-surfaces with reason. No item on this screen is decorative.
States shown
Use the state control at the top: complete data, first-run, loading, empty, and degraded service. All five are the same layout with different content — no separate screens.
