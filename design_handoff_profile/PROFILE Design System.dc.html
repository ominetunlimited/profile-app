Plus Jakarta Sans for headings only (h1–h3 / page titles — bold, distinctive, merged in from the Figma-Make source). Inter for the interface, IBM Plex Sans for dense data tables, JetBrains Mono for anything a person might need to read character by character. All sizes are fluid via clamp; nothing below 12px ships.

04

Motion

Three durations, one easing curve, one exception. Motion confirms a change happened; it never announces itself.

Durations
120ms — hover, focus, colour
200ms — dropdowns, toasts, tabs
320ms — modals, drawers, route change
cubic-bezier(.22,.61,.36,1)
The logo replaces every spinner
Standing in for <ProfileLogoAnimated> (§3.11) — one shared component with loading, idle, error, warning and success states.
Rules
Transform and opacity only. No infinite animation outside a genuine pending state. Failure never rests as a static end state — it settles into a pulse next to a retry. Everything is gated on prefers-reduced-motion, which this page honours.

08

Accessibility floor

WCAG 2.2 AA across the whole product (§2.4). These are gates, not aspirations — a component failing any of them does not ship.

Contrast
4.5:1 for body text, 3:1 for text above 24px and for UI boundaries. Brand hexes are overridden per theme where they fail — Trust Cyan is #00E5FF on dark and #0E7490 on light for exactly this reason.
Focus
Focused
A 2px ring at 2px offset, on :focus-visible only. Never removed, never replaced by colour change alone.
Status is never colour alone
Every state carries a glyph and a word. A verified badge reads "✓ Verified" to a screen reader and to someone who cannot distinguish cyan from green.
Keyboard and touch
Every interactive element reachable by keyboard in visual order, skip link on every page, 44×44 minimum touch target, and no interaction that requires hover to discover.
